# 訪問して売れる仕事の事業比較

共有URL： https://ryoto-6174.github.io/chiba-business-100/

千葉市周辺・車なし・初期資金1万円を条件とした130案の比較レポートです。
追加30案（101〜130）は清掃以外の戸別訪問・小作業・地域配布に寄せ、「新規」を付けています。

- 130案それぞれの市場、収益仮説、競合、拡大条件
- 旧100案は各30回、追加30案は24〜25回、計3740組の検討記録
- 追加30案のみの絞込みと訪問適合の評価

`public-catalog.json`は公開レポートの表示用出力データです。会社のソース、内部台帳、原入力、認証情報は含めていません。
GitHub Actionsが同じcommitから静的ページを生成・検査し、GitHub Pagesへ配備します。
ローカルの空き物理メモリが2GiB未満の場合、生成スクリプトはローカル実行を拒否します。

初回調査2026年10月27日、追加更新2026年10月28日。価格・受注・費用・利益・訪問成約率は仮説と実績を区別しています。
